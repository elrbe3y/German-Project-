What Is Cyber Security?

Cyber security is the practice of protecting computers, networks, programs, and data from unauthorized access, attack, damage, or theft.

🔐

Confidentiality

Information is only visible to people who are authorized to see it, for example through encryption.

🧾

Integrity

Data stays accurate and unchanged unless an authorized person changes it, for example through hashing.

⚡

Availability

Systems and services remain accessible when users need them, even during attacks like DDoS.

Common Types of Attacks

  • • Phishing: fake messages that trick people into revealing information.
  • • Ransomware: malware that encrypts files and demands payment.
  • • Malware: malicious software such as viruses and trojans.
  • • SQL Injection / XSS: flaws in websites that allow data theft.
  • • Social Engineering: manipulating people instead of machines.
  • • DDoS: flooding a server with traffic until it stops working.

Specializations

The main areas of cyber security and what each one focuses on

🎯

Ethical Hacking & Pentesting

Authorized attacks on systems to find vulnerabilities before real attackers do.

🌐

Network Security

Firewalls, intrusion detection and prevention, and securing network infrastructure.

💻

Web & Application Security

Protecting websites and apps against OWASP Top 10 risks and insecure code.

🔍

Digital Forensics

Collecting and analyzing digital evidence to understand how an incident happened.

📡

SOC & Security Monitoring

Round-the-clock monitoring, log analysis, and threat detection with SIEM tools.

☁️

Cloud Security

Securing AWS, Azure, and GCP environments, including identity and access management.

Subjects

The core topics students study, roughly in the order they build on each other

Networking Fundamentals

The OSI and TCP/IP models, IP addressing, DNS, HTTP, and how data moves between devices.

  • • OSI & TCP/IP models
  • • IP addressing & subnetting
  • • DNS, HTTP, DHCP

Operating Systems

Linux command line and Windows administration, including Active Directory.

  • • Linux & Terminal commands
  • • File permissions & processes
  • • Windows & Active Directory

Programming & Scripting

Python for automation and scripts, plus HTML and JavaScript to understand web vulnerabilities.

  • • Python scripting
  • • Bash basics
  • • HTML & JavaScript

Cryptography

Symmetric and asymmetric encryption, hashing, and how SSL/TLS protects communication.

  • • Encryption & hashing
  • • Public key infrastructure
  • • SSL/TLS

Web Application Security

OWASP Top 10, SQL injection, XSS, CSRF, and secure coding practices.

  • • OWASP Top 10
  • • SQL Injection & XSS
  • • Secure coding

Penetration Testing & Forensics

Testing methodology with tools like Nmap, Burp Suite, and Metasploit, plus evidence analysis.

  • • Recon, scanning, exploitation
  • • Burp Suite & Nmap
  • • Disk & memory forensics

Career Paths

Common job roles in cyber security and what each one does day to day

🛡️

SOC Analyst

Monitors security alerts, investigates suspicious activity, and separates real attacks from false alarms.

SIEM Log Analysis
🎯

Penetration Tester

Tests systems with permission and writes reports with vulnerabilities and how to fix them.

Web Testing Reporting
🔍

Digital Forensics Investigator

Investigates cyber crimes, preserves evidence, and supports legal and incident response teams.

Evidence Handling Malware Analysis
🚨

Incident Responder

Responds first during an attack to contain it, remove the cause, and restore services.

Containment Recovery
🏗️

Security Engineer

Builds, deploys, and maintains security tools and infrastructure such as firewalls and EDR.

Firewalls Automation
📜

GRC Analyst / Auditor

Reviews policies, assesses risks, and makes sure the organization meets standards like ISO 27001.

ISO 27001 Risk Management

Where Cyber Security Professionals Work

Banks, telecom companies, hospitals, government agencies, security consulting firms, cloud and software companies, and freelance work in penetration testing and bug bounty programs.

Certifications

Industry certifications that prove your skills, from beginner to advanced level

CompTIA Security+

Beginner

The best starting point for anyone entering cyber security. Vendor-neutral and widely recognized.

Cisco CCNA

Beginner

Builds a solid understanding of networking, which is essential for security work.

CompTIA CySA+

Intermediate

Focused on threat detection and analysis, ideal for SOC analyst roles.

CEH

Intermediate

Certified Ethical Hacker by EC-Council, an introduction to ethical hacking methods and tools.

OSCP

Advanced

A hands-on penetration testing certification by OffSec, highly respected in the industry.

CISA

Advanced

Information systems auditing certification by ISACA, great for audit and GRC careers.

Requirements and fees change over time. Always check the official website of each certification body.

Learning Path

A suggested roadmap for someone starting from scratch

1

Computer & Networking Basics

Learn IP addresses, DNS, and the OSI model, along with Linux and the command line.

2

Learn Basic Programming

Python is enough to start with, and HTML/JavaScript helps you understand the web.

3

Pick a Specialization

Focus on one path such as Pentesting, SOC, or Forensics instead of spreading too thin.

4

Practice Hands-On

Use platforms like TryHackMe, Hack The Box, and PortSwigger Academy, and build a home lab.

5

Get Certified and Build a Portfolio

Earn a beginner certification and publish your projects and write-ups on GitHub or a blog.
